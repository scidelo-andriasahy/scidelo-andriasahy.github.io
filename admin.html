Workflow POSSE (« Publish on Own Site, Syndicate Elsewhere ») sans toucher à Git :
1. Rédigez ou modifiez un article dans l'onglet ✍️ Blog & POSSE ci-dessous.
2. Cliquez sur 🚀 Publier en 1 Clic (GitHub API) (si vous avez renseigné votre Token GitHub dans l'onglet Automatisation) OU téléchargez content.js + feed.xml.
3. Dès que feed.xml est mis à jour sur GitHub Pages, votre scénario Make.com / Zapier / Buffer / Dev.to diffuse automatiquement votre article sur tous vos réseaux avec l'URL canonique officielle !
